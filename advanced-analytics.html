▣ Data Integrity

Browser Data đọc localStorage key axiom_trades_v1 ở chế độ chỉ đọc. Backup JSON được phân tích trong bộ nhớ của trang, không tự nhập hoặc ghi đè vào Journal.

Nếu mở bằng file:// từ ZIP, dữ liệu localStorage có thể không giống dữ liệu của website GitHub Pages. Hãy dùng nút Read Backup JSON để thử với một bản sao lưu.
